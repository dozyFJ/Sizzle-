## Сборка

JDK 17 или 21, Android SDK 35. Укажите SDK через `ANDROID_HOME` или `local.properties`.

```sh
./gradlew assembleRelease lintRelease
```

Для подписи используйте только отдельный ключ Sizzle. Текущий демонстрационный ключ хранится локально в `.signing/sizzle-demo.jks`, пароль — в `.signing/password` (оба исключены из Git). Сохраните их в надёжном хранилище для последующих обновлений этого APK. Для будущего production-релиза следует отдельно определить постоянную схему подписи.

```sh
export SIZZLE_KEYSTORE_PASSWORD="$(cat .signing/password)"
./scripts/sign-apk.sh
```

Результат: `app/build/outputs/apk/release/Sizzle-0.1.0.apk`.

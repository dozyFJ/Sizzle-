# Sizzle

Окремий банківський Android-застосунок для України на Kotlin та Jetpack Compose.

[Завантажити підписаний APK 0.2.0](https://raw.githubusercontent.com/dozyFJ/Sizzle-/main/downloads/Sizzle-0.2.0.apk) · Android 8.0+

## Версія 0.2.0

Material 3, світлі бетонні поверхні, графітові картки, помаранчевий акцент і технічна моноширинна типографіка. Інтерфейс українською, усі суми — у гривнях.

Головний екран: загальний баланс із приховуванням сум, дві картки, поповнення, переказ і оплата з перевіркою суми та демонстраційним переглядом, історія операцій з українськими прикладами.

Дані вигадані. API, мережеві дозволи й реальні платежі відсутні. Баланс дорівнює сумі балансів карток. Історія — ілюстративна вибірка, не повний реєстр. Додаткову навігацію поки не додано.

Application ID: `app.sizzle.bank`. Код, дані та ключі Pulse не використовуються.

## Збірка

JDK 17 або 21, Android SDK 35. Вкажіть SDK через `ANDROID_HOME` або `local.properties`.

```sh
./gradlew assembleRelease lintRelease
```

## Підпис

Окремий демонстраційний ключ Sizzle зберігається локально в `.signing/sizzle-demo.jks`, пароль — у `.signing/password`. Обидва файли виключено з Git. Ключ той самий, що у версії 0.1.0, для встановлення оновлення. Збережіть ключ та пароль у захищеному сховищі. Для production-релізу потрібно окремо визначити постійну схему підпису.

```sh
export SIZZLE_KEYSTORE_PASSWORD="$(cat .signing/password)"
./scripts/sign-apk.sh
```

Результат: `app/build/outputs/apk/release/Sizzle-0.2.0.apk`.

Перевірки та обмеження конкретної збірки наведено в нотатках до релізу.

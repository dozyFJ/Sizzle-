# Sizzle

Окремий банківський Android-застосунок для України на Kotlin та Jetpack Compose.

[Завантажити підписаний APK 0.4.1](https://raw.githubusercontent.com/dozyFJ/Sizzle-/main/downloads/Sizzle-0.4.1.apk) · Android 8.0+

## Версія 0.4.1

Material 3: темний фон, шапка-капсула з м’яким градієнтом, округлі графітові панелі, вкладки-пілюлі та помаранчевий акцент. Візуальний напрям адаптовано за наданим скриншотом Pulse; код, дані й ключі Pulse не використовуються. Інтерфейс українською, усі суми — у гривнях.

Головний екран: дві картки одразу під вкладками, приховування сум, вузькі кнопки-пілюлі з іконкою ліворуч і текстом праворуч, поповнення, переказ і оплата з перевіркою суми та демонстраційним переглядом, історія операцій обраної картки у нижній панелі (bottom sheet), що відкривається натисканням на картку. Загальний баланс та історію з головного екрана прибрано.

Дані вигадані. Банківський API та реальні платежі відсутні. Інтернет використовується лише для перевірки й завантаження оновлень Sizzle з GitHub. Баланс дорівнює сумі балансів карток. Історія — ілюстративна вибірка, не повний реєстр. Під шапкою — вкладки-пілюлі «Головна», «Послуги», «Гаманець». Вибрана вкладка зберігається при повороті екрана. У послугах — демоформи мобільного зв’язку, комунальних послуг, інтернету й платежу за IBAN; у гаманці — картки.

Application ID: `app.sizzle.bank`. Код, дані та ключі Pulse не використовуються.

## Збірка

JDK 17 або 21, Android SDK 35. Вкажіть SDK через `ANDROID_HOME` або `local.properties`.

```sh
./gradlew assembleRelease lintRelease
```

## Підпис

Окремий демонстраційний ключ Sizzle зберігається локально в `.signing/sizzle-demo.jks`, пароль — у `.signing/password`. Обидва файли виключено з Git. Ключ той самий, що у версії 0.1.0, для встановлення оновлення. Збережіть ключ та пароль у захищеному сховищі. Для production-релізу потрібно окремо визначити постійну схему підпису.

```sh
export SIZZLE_KEYSTORE_PASSWORD="$(cat .signing/password)"
./scripts/sign-apk.sh
```

Результат: `app/build/outputs/apk/release/Sizzle-0.4.1.apk`.

Перевірки та обмеження конкретної збірки наведено в нотатках до релізу.

## Оновлення в застосунку

Під час запуску застосунок перевіряє `updates/latest.json` у гілці `main`. Кнопка «Оновлення» в шапці запускає перевірку вручну. Мережевий збій при автоматичній перевірці не блокує екран. Завантаження починається лише після згоди користувача.

Метадані містять versionCode, versionName, URL APK з незмінного commit SHA та SHA-256. Дозволено лише HTTPS-завантаження з `raw.githubusercontent.com/dozyFJ/Sizzle-/`. Перед встановленням перевіряються SHA-256, application ID, точний номер версії та відповідність сертифіката встановленому Sizzle. Ліміт APK — 100 МіБ. APK зберігається у приватному кеші та передається інсталятору через FileProvider.

Android потребує дозволу «Встановлення невідомих застосунків» для Sizzle і підтвердження кожного встановлення. Автоматичного фонового встановлення немає. Версії до 0.3.0 потрібно один раз оновити вручну.

Публікація наступного оновлення:

1. Збільшити versionCode та versionName, оновити шлях APK у scripts/sign-apk.sh.
2. Зібрати, перевірити та підписати APK тим самим ключем Sizzle.
3. Скопіювати APK у downloads/ і закомітити вихідний код та APK.
4. Запустити `python scripts/prepare-update.py`. Скрипт створить метадані з APK, уже записаного в поточному коміті.
5. Закомітити updates/latest.json та відправити main на GitHub. За потреби створити реліз.

Тести політики оновлень: `./gradlew testReleaseUnitTest`. Повний сценарій встановлення потрібно перевірити на Android-пристрої.
